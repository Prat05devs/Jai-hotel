# Jai Hotel

React/Vite website for Jai Hotel in Mandal Valley, focused on stay discovery, WhatsApp booking requests, and itinerary planning for Chopta, Rudranath, Gopeshwar and Char Dham travelers.

## Run Locally

Prerequisite: Node.js with Yarn 1.x.

```bash
yarn install
yarn dev
```

## Quality Checks

```bash
yarn lint
yarn build
```

## Contact Details

Public contact, WhatsApp, directions and social links are centralized in `src/constants.ts`.
